# Project guidance

Keep this project local, simple, and beginner friendly. The current scope is PDF based RAG with sentence-transformers, ChromaDB, and Ollama. Do not add web frameworks, LangChain, cloud services, fake university data, or unrelated dependencies.

Explain each meaningful section in plain language. Preserve real source filenames and page numbers from PDFs. Keep generated databases, private documents, credentials, and virtual environments out of Git.
